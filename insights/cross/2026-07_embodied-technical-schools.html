      路线赛点
      端到端 vs 分层

      姊妹篇：具身智能 × 世界模型 · 全景地图与判断台（做广度扫描 + 玩家阵营）。这一篇是补充的深度篇 —— 广度篇告诉你「谁在场上」，深度篇告诉你「他们在打什么」。

      核心结论："具身智能"不是一种技术方案，而是五种正在博弈的架构——它们分居在感知/决策/控制/数据四个抽象层：VLA 端到端（控制层主力）、Diffusion / Flow Policy（动作头范式）、世界模型 + 规划（感知/规划外挂）、LLM 分层（决策层的慢思考）、模仿学习管线（所有方案的公共数据底座）。理解这五种的分工比追任何一家公司的发布会更有信号。上一篇姊妹文里我说 π0.5 是"生成派"，那是松散归类——π0.5 严格说是「VLA 骨干 + Flow 动作头」，本文正好把这类术语先规整清楚。
      一页要点
      • 不要把"具身智能"当一种技术——它是四个抽象层上五种流派的合称，每层各有各的当红方案。
      • VLA 是当下商用主战场（RT-2 → OpenVLA → π0 → π0.5 → Helix），一个大模型端到端吐动作。
      • Diffusion / Flow Policy 不是独立流派，而是"动作头"——它已被 VLA 吸收成组件（π0 家族）。
      • 世界模型分生成派（Sora/Cosmos/Genie）和判别派（V-JEPA/JEPA），两派赌"什么才是学到物理"，2027 前赛点见分晓。
      • LLM 分层是长任务的现实解——SayCan / Code-as-Policies / Helix System 2，语言 = 慢思考、底层 = 快反应。
      • 模仿学习管线是公共底座——遥操作数据没有替代品，谁的真机部署量大，谁的模型迭代快。

      一先规整术语：六个词不通、下面全糊#

      Vocabulary · 一次性把术语拆干净

      下面六个词是本文（也是这个方向所有讨论）的基础词。它们互相不对等，但经常被混用——比如把 "Diffusion Policy" 和 "VLA" 当同类比，其实一个是"动作头"一个是"整机架构"；把 "Policy" 和 "World Model" 当同类比，其实一个决定"做什么"一个是"预判做完会怎样"。

      Policy 策略
      π(a|s)

      "看到什么状态该做什么动作"的函数——机器人所有可训练模块的通用名。VLA、Diffusion Policy 都是不同实现的 policy。

      VLA
      Vision-Language-Action

      一个大模型端到端吃图像+语言指令、直接吐动作——把 VLM（视觉语言模型）+ 动作生成头合成一个整机。代表：RT-2、π0。

      World Model 世界模型
      f(s,a)→s'

      "脑内仿真器"——给我当前状态和一个动作，预测下一个状态。有它就能在头脑里 rollout、搜索、规划。分生成式（重建像素）和判别式（只学表征）。

      Diffusion / Flow
      Action Head

      不是独立方案，是"动作头"的新范式——把动作序列当分布采样。Flow Matching（π0/π0.5 用的）是扩散的高效近亲，一到几步就出结果。

      Sim2Real
      仿真到真机

      先在仿真里训练，再迁移到真机——省数据也省摔机器人。工具链：Isaac Sim / MuJoCo / Cosmos。核心难点是"仿真的物理不完全对"。

      Behavior Cloning
      BC · 行为克隆

      用人类示范监督学习一个策略——是所有真机 policy 最古老、也最有效的训练范式。ALOHA、π0、Helix 都靠它。

      二抽象层级：五个方案分居四层#

      The Stack · 别把控制层和感知层拿来比谁强

      下面把五个方案按它们在"具身系统"里的工作层归位。这一步做好了，"π0.5 vs V-JEPA 2 谁更强"这类问题就自动消失——它们不在同一层。

      L1
      感知 & 想象Perception · World Model

      把原始摄像头/关节读数压缩成潜空间表征；有能力的话还能预测"下一步世界长什么样"。这是"脑内仿真器"的落脚点。

      世界模型 Dreamer V-JEPA 2 Cosmos Genie 3
      L2
      决策 & 规划Planning · Task Decomp.

      收到"把桌子收拾干净"这种粗粒度指令，拆成有序的原语动作——"打开抽屉→拿海绵→擦桌子→放回海绵"。是"慢思考"层，天然由 LLM 承担。

      LLM 分层 SayCan Code-as-Policies Voxposer Helix S2
      L3
      控制 & 动作Control · Actuation

      拿到一个具体子任务（"抓这个杯子"），输出关节角/末端力——直接驱动电机。是"快反应"层，需要毫秒级闭环。当下所有 SOTA 都堆在这里。

      VLA Diffusion/Flow Policy RT-2 π0 · π0.5 OpenVLA Helix S1
      L0
      数据 & 训练Data · Training Pipeline

      所有 L1-L3 的食粮供给——遥操作、仿真、真机自主、互联网视频。这一层被误当"苦力活"，实则是护城河真正长出来的地方。

      模仿学习管线 ALOHA DROID Bridge V2 Isaac + Cosmos
      看这张栈能得到什么
      • π0.5 在 L3（控制层），V-JEPA 2 在 L1（感知层）——它们理论上应该合作而不是竞争：一个当大脑一个当手脚。
      • Helix 是 L2 + L3 的组合拳（System 2 = LLM 分层，System 1 = VLA 控制），这是当前架构上最"整机"的实现。
      • 所有 SOTA 的共同底座是 L0——PI/Figure/1X 拼的不是"我模型比你好"，是"我的遥操作时长比你多 5 倍"。

      三五大方案：每张卡片一个流派#

      Five Schools · 骨架 + 代表 + 优劣 · 每卡三分钟看完

      01端到端 VLAVision-Language-Action · 大一统主流

      ★★★★☆ 部署成熟度

      一句话：把 VLM（视觉语言模型）当骨干、接一个动作生成头，一个模型端到端吃「图像 + 语言指令」直接吐动作。

      关键机制：

      • 动作 tokenization（RT-2 路线）：把动作离散化成 token，跟语言 token 一起自回归。简单但精度受限。
      • 连续动作头（π0 / OpenVLA 路线）：接 diffusion / flow matching 头，一次吐一整段 chunk（如 50 步 × 7 维），精度高但训练贵。
      • Chunked prediction：不预测单步，而是一整段动作序列——避免"帧间抖动"，提高稳态。
      • 训练数据配方：VLM 预训练（互联网视频/图文） + 遥操作真机数据混合微调。
      代表玩家
      RT-2 (2023) OpenVLA (2024) π0 · π0.5 (PI) Helix S1 (Figure) Gemini-Robotics
      优
      跨任务泛化好；能直接吃 VLM 预训练的语义先验。
      劣
      真机数据永远不够；长尾任务需要遥操作补，成本高。

      02Diffusion / Flow Policy动作生成头范式 · 已被 VLA 吸收

      ★★★★★ 作为组件普及度

      一句话：把机器人动作当"分布"，用扩散模型（去噪）或它的高效近亲Flow Matching采样出一整段动作 chunk。

      关键机制：

      • 相比 BC 的核心优势：处理"多模态动作分布"——同一个观测下有多种合理动作时，BC 会取平均（错的），扩散会保留多峰。
      • Flow Matching（π0/π0.5 采用）：不像扩散要几十步去噪，一到几步就能采样，推理速度提升 10× 以上。
      • 严格说不是"独立架构"：它是动作头——上面接什么骨干都行（ResNet、Transformer、VLM 都用过）。
      • 3D Diffusion Policy / DP3：加 point cloud 输入，处理 3D 空间任务更强。
      代表玩家
      Diffusion Policy (TRI/Columbia, 2023) RDT-1B 3D DP π0 · π0.5 (作为组件)
      优
      多模态动作不塌陷；输出平滑连续。
      劣
      不含语义 / 语言理解，必须跟 VLM 配对。

      03世界模型 + 规划World Model + Planning · 感知/规划外挂

      ★★☆☆☆ 真机部署成熟度

      一句话：先训一个"脑内仿真器"能预测未来状态，然后在其中搜索 / 规划最优动作序列。

      关键机制 & 两条分支：

      • 生成派（Dreamer / Cosmos / Genie）：世界模型输出重建的像素 / 视频，训练目标是"预测像素"。信号密但含大量物理无关噪声。
      • 判别派（V-JEPA 2 / TD-MPC / JEPA 全家）：只在潜空间预测未来表征，不重建像素——LeCun 认为像素级预测浪费算力。
      • 规划器：拿到世界模型后，用 MPC（模型预测控制）或 MCTS 采样式搜索找最优动作。天然分层结构。
      • 核心难题：模型失真会累积——rollout 5 步还行，rollout 50 步就漂了；工程上很难。
      代表玩家
      Dreamer V3 (2023) TD-MPC2 V-JEPA 2 (Meta) Cosmos (NVIDIA) Genie 3 (DeepMind)
      优
      数据效率高——"想象"可无限扩充；天然可解释。
      劣
      真机部署 SOTA 极少；模型误差累积严重。

      04LLM 分层Hierarchical · 慢思考 + 快反应

      ★★★★☆ 长任务成熟度

      一句话：LLM 做"慢思考"（把粗粒度指令拆成原语序列），底层策略做"快反应"（毫秒级闭环执行）。Figure 的 Helix "System 1 + System 2" 是当红代表。

      关键机制：

      • SayCan（2022, Google）：LLM 打分"这一步合不合理" × affordance 打分"这一步能不能做"，联合选下一步。
      • Code-as-Policies（2022）：LLM 直接生成 Python 代码调用一组预定义 skill API——最可解释、最可 debug。
      • Helix System 1+2（Figure, 2025）：VLM 慢思考（7-9Hz 全局理解）+ VLA 快反应（200Hz 闭环控制），是当前最激进的双系统整机。
      • Voxposer：LLM 直接生成 3D affordance 场，把语义映射到空间。
      代表玩家
      SayCan (2022) Code-as-Policies Voxposer Helix (Figure, 2025) Gemini-Robotics ER
      优
      可解释、可组合；天然支持长任务与人机协作。
      劣
      底层 skill 边界要预先定义；LLM 的物理直觉薄。

      05模仿学习管线Imitation Learning Pipeline · 所有方案的公共底座

      ★★★★★ 工业化成熟度

      一句话：不是模型架构，而是数据供给方式——人工远程操控机器人做示范，收集 (观测, 动作) 轨迹训练策略。所有 L1-L3 方案都靠这条流水线喂饭。

      关键机制：

      • 遥操作硬件生态：ALOHA（斯坦福双臂）、GELLO、Apple Vision Pro + 手部追踪、Meta Quest + 手柄——把"如何优雅示范"变成硬件问题。
      • 训练算法可以是 BC、Diffusion Policy、VLA——它们只是模型选型，共享同一条数据流水线。
      • 数据规模是所有 SOTA 的暗线：PI 的 π0 训练用了约 10,000 小时遥操作；Figure 目标做到 100,000 小时。
      • 真正的护城河：真机部署后的自主运行数据回流——这才是"具身版飞轮"。
      代表玩家 / 数据集
      ALOHA (Stanford) DROID (2024) Bridge V2 Open X-Embodiment PI 内部数据
      优
      真机保真度最高；直接对齐部署分布，无 Sim2Real gap。
      劣
      贵、慢、覆盖窄；需要千小时级人力。

      六专题对比：π0.5 vs V-JEPA 2，为什么这场"PK"其实是错位#

      Deep Dive · 一张架构图 + 一张 16 维对比表

      先说结论

      π0.5 和 V-JEPA 2 不是竞品，是"栈的不同层"。π0.5 是 Policy（决策 + 控制）；V-JEPA 2 是 Representation / World Model 表征骨干（感知）。硬要 PK 就像问"BERT 和 GPT 哪个厉害"——2018 年这么问尚可，2026 年这么问基本没意义，因为两者根本不解决同一件事。真正有意义的对比是：π0.5 vs Diffusion Policy / OpenVLA / RT-2（同层横评），V-JEPA 2 vs V-JEPA / DINO-WM / IRIS（同层横评）。

      两者的信息流根本不重合：π0.5 学「怎么动」，V-JEPA 2 学「世界是什么」。

      如果你在想"要不要 fuse 两者"

      这正是 2026 年最热的研究方向之一：用 V-JEPA / DINO-WM 当 VLA 的视觉骨干（替代 SigLIP），让 policy 拿到"懂物理"的表征。已有若干论文尝试（DINO-WM policies · V-JEPA policies），初步结果显示数据效率提升 3-10×，但真机长任务成功率还没稳定超过 SigLIP-VLA。2027 前若 V-JEPA-VLA 组合能横扫 DROID benchmark，就是"判别派世界模型"真正的胜利时刻。

      七判断台：五张时机 / 信心票#

      The Verdicts · 每个方案给一张钤印

      01 · 端到端 VLA
      时机：进行中信心：高

      是当下商用主战场；每 3-6 个月出一代 SOTA。押注这一路 = 押注"端到端 scaling 会赢"。短期最稳，长期看 scaling law 是否在具身场景成立。

      02 · Diffusion / Flow Policy
      时机：已发生信心：高

      作为"动作头组件"已被主流吸收；Flow Matching 相对 Diffusion 的推理加速已是共识。2026 后不再是独立争议点，只是标配。

      03 · 世界模型 + 规划
      时机：1-2 年信心：中

      生成派做数据引擎 / ToC 娱乐已能变现；判别派（V-JEPA）做真机 policy 尚在实验室。2027 前赛点：V-JEPA 2 在具身 benchmark 是否能打过 π0.5。

      04 · LLM 分层
      时机：进行中信心：中

      05 · 模仿学习管线
      时机：已发生信心：高

      是唯一没有争议的一层——所有 SOTA 都要它喂饭。当前的真机部署数据护城河将持续 2-3 年，直到 Sim2Real 或视频预训练真的能顶上（大概率不会那么快）。投入这一层最稳。

      八给读者的实用地图：怎么用这张知识#

      Mapping · 从概念到判断

      看一家公司 / 一篇论文时可以怎么问
      1. 他们工作在哪一层？（L0 / L1 / L2 / L3）—— 直接决定它能不能被同类比较。
      2. 用了哪些方案的组合？—— 只做一个方案的公司很少，看清组合才能判断"缺哪块"。
      3. 数据从哪里来？—— 遥操作时长、仿真管线、视频源，是 L0 的三条真实指标。
      4. 动作头是什么？—— token 化、diffusion、flow matching 意味着不同的精度/速度权衡。
      5. System 2 有没有？—— 短任务不需要，长任务不用会崩。判断该系统"能不能做长链任务"。
      6. Sim2Real 依赖度多高？—— 依赖仿真越重、真机保真度越低，Demo 和上线的差距越大。

      回到你上一篇姊妹文最后遗留的那个问题——「π0.5 是不是生成式，跟 V-JEPA 2 比谁强」——用这张地图重答就是：π0.5 是 L3 的 VLA（其中动作头是生成式的 flow matching），V-JEPA 2 是 L1 的判别式世界模型；它们不在同一层，谁"强"取决于你的问题是"现在能不能装机干活"（π0.5 赢）还是"未来能不能少数据学新任务"（V-JEPA 2 赌的方向）。这就是"知识地图"的价值：把伪命题过滤掉，只留下真问题。
