      三共识架构 · 五层同心圆#

      — What everyone agreed on, without agreeing

      把四家的架构图叠在一起，重合的部分出奇地一致。这不是因为互抄，是因为"Agent 要替用户干活"这件事从技术约束上只能这么做：没有 VM 隔离就不敢给凭据，没有 Sentinel 就不敢让它上网，没有一次性卡就不敢让它付钱。

      ① 独立云端 VM

      Muse Secure VM · Dot 云电脑 · Grok Bot cloud computer · Instinct "its own phone and computer" —— Agent 不住在聊天框里，有自己的隔离沙箱。

      ② 浏览器 + 登录态

      可以打开网页、填表单、维持会话。Grok Bot 的卖点就是"工作在真实工具里完成，不是在 chat 草稿里"。

      ③ Connectors

      Muse 一次点击接 Canva / Shopify / Stripe / Figma / Notion…；Dot 可连 4000+ 应用；Instinct 直接拿你的 iMessage / 邮箱 / 日历。

      ④ 审批 Sentinel

      Muse 的 Sentinel 单独 agent 审出站流量；Dot 敏感动作前必问；Instinct active detective 捕获幻觉；审批点变一等公民。

      ⑤ 一次性虚拟卡

      Muse 和 Instinct 都接 Stripe Link：Agent 替你付钱，拿不到真卡号。这不是技术选型，是信任协议的物化。
      判断

      这五层会沉淀成"个人 Agent 操作系统"的事实标准。谁家 agent 没有这五件事，谁就上不了桌 —— 就像今天没有沙箱的浏览器插件也上不了 Chrome Web Store。

      四真正的分化在两个轴#

      — Where the four actually bet differently

      共识是地基，分化才看出赌注。把四家按两个轴摆出来，就能看清各自在押什么：横轴是目标用户（专业工作者 ↔ 普罗大众），纵轴是入口形态（独立 app ↔ 挂载到用户已在的 IM）。

      ① 专业 · 独立 app
      Grok Bot
      开发者 / Cursor 用户。多 Bot 分部门，依附 SuperGrok 和 Cursor 的订阅捆绑。赌工程师愿意为 Agent 新开一个 app。
      ② 普罗 · 独立 app
      Muse
      数十亿人的消费级。免费 + 订阅，Meta 规模赌"开箱即用，无学习曲线"就是最大护城河。同时也走 WhatsApp 捷径，脚踏两船。
      ③ 专业 · 挂 IM
      Dot
      企业专业工作者。挂 ChatGPT / Slack / Teams，把工作面升级成"办公室"而不是另开 app。企业 Dot 甚至拥有组织内身份。
      ④ 普罗 · 挂 IM
      Instinct
      中产以上懒得办事的 C 端。挂 iMessage + 电话，没有新 UI。23 岁创始人赌：个人意图接管权是消费软件终局之战。

      横轴：目标用户（左=专业 / 右=普罗）　纵轴：入口形态（上=独立 app / 下=挂 IM）

      4.1 分化透露的赌注

      • Muse 的赌注是"规模即护城河"：Sensor Tower 报告它发布头几天 73 万次下载，比 Meta AI app 首发还多。Meta 相信只要能把 Agent 塞进 billions 用户的 WhatsApp，模型追赶是时间问题。
      • Dot 的赌注是"Agent 有身份即员工化"：企业 Dot 在组织内有独立 job title，这是把 Agent 从"工具"抬成"编制"的尝试。
      • Grok Bot 的赌注是"工程师更愿意为自己的编制买单"：靠 SuperGrok Heavy / Cursor Ultra 等高价订阅，不走补贴路线。
      • Instinct 的赌注是最激进的 —— "认知裁量权让渡"。详见下一节。

      五真正的护城河 · 认知裁量权#

      — The real moat is trust, not tokens

      如果 5 层架构会被所有家拉齐，模型能力又在"模型接入被商品化"的大势里趋同，那么个人 Agent 的真正差异化在哪？Nextie 创始人李笛的说法最到位：看用户什么时候敢把"你来定"三个字交给 Agent。这是比订阅费大一个数量级的生意。

      AUTHORITY LADDER · 用户让渡给 Agent 的权限深度
      前两格现在的 chat 都能做；第三格是分水岭 —— 价格、距离、口味、过去踩过的坑放进同一个决策，Agent 替人做判断。Instinct 用户已经把钱包递过去：平均每人每月经由它支出 $1,300，场景覆盖国际旅行、日用品、瑜伽课、汽车维修。即便抽 1%，一个活跃用户一年也是约 $156 ARPU —— 对比 ChatGPT 月费，这是数量级的差异。
      风险

      但裁量权让渡也会翻车。有投资人 Jason Yeh 只让 Instinct"找"有空位的餐厅，它直接替他订下了一个 取消费 $200 的座位。这个边界事故 = 技术成本（$200）＋ 信任成本（下一次用户会不会收回"你来定"）。

      六对 LIFT 和 FDE 工作的影响#

      — What this means for eval + attribution

      三个直接传导
      • L1 错误分类里"擅自决策"将成高频类目。Instinct 餐厅事故就是典型"越权执行" —— 现有 AgentErrorTaxonomy 里要把这类从"工具使用错误"独立出来、按"用户授予的裁量权等级 vs Agent 实际消耗的裁量权等级"打分。
      • 审批点变一等公民 → 归因必须区分"Agent 的功"与"用户的锅"。当四家都把 Sentinel / active detective / 用户确认做成架构级组件，评测口径里就必须显式记录"这一步是 Agent 决定的，还是用户通过审批追认的"，否则归因会算错账。
      • 连接器爆发 = 轨迹采集面骤增。Muse 一键接 Canva / Shopify / Stripe / Figma / Notion，Dot 支持 4000+ 应用 —— LIFT 的 Trace 层要能标准化这些跨 app 的产物与打分，否则归因到不了 L2。

      6.1 我们该做什么（1–2 周）

      行动
      1. 把"认知裁量权"写进 LIFT 的 L1 错误库 —— 作为与"工具调用错误"、"工程失误"并列的独立维度。
      2. Trace schema 里补一个 approval_point 字段 —— 记录每个敏感动作是 Agent 自决还是用户追认。
      3. 找一款可触达的个人 Agent（Grok Bot 最可行，SuperGrok Heavy / Cursor Ultra 用户可以直接用）跑通一轮 FDE 实验：同一任务让它跑 10 次，看裁量权消耗的分布是不是稳定。

      七待观察的开放问题#

      1. IM 挂载 vs 独立 app 哪条路跑赢？看 Grok Bot 6–12 个月的留存和 Instinct 的 iMessage 转化率。
      2. 多 Agent 协作是不是伪需求？Dot 和 Grok Bot 都在押多 Agent 组队，但目前所有 benchmark 都是单 Agent 的；企业场景里真的需要吗？
      3. 一次性卡能撑住多大 TPV？Instinct $1,300 / 用户 / 月 × 10 万用户 ≈ 月 1.3 亿美金流水 —— 到 100 万用户的时候，Stripe Link 的欺诈率曲线会不会反噬？
      4. Meta 规模路线会不会把其他三家挤出 toC？Muse 免费 + 2026 Q4 WhatsApp 全球铺开 —— Instinct 的 $10B 估值能守住吗？
      5. 模型谁家胜出不再决定 Agent 谁家胜出。如果这个判断成立，模型厂的护城河会不会反而掉队到应用层下面？
